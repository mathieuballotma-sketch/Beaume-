# Signaler un problème de sécurité

Beaume est un prototype ; aucune version n’est actuellement annoncée comme
validée pour l’usage de données clients confidentielles.

Ne publiez pas de dossier client, clé API, journal contenant des pièces ou détail
exploitable dans une issue publique. Utilisez le signalement privé GitHub lorsqu’il
est disponible ; sinon demandez un canal confidentiel sans publier le détail.

Inclure version, environnement et reproduction synthétique. Les téléchargements,
le service Ollama, les journaux et les dépendances font partie du périmètre à auditer.
