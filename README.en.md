# Beaume — English overview

Beaume is an early local document-assistance prototype for lawyers.
It aims to help them review case files, find sources and consider relevant legal texts.
**It assists lawyers; it does not replace their professional judgment or decisions.**
The published demo uses fictional material and a fixed response, without a model.
The main experimental pipeline can use a local model through Ollama.
A separate laboratory explores OCR, inference and Swift calculation components.
Those experiments are not a complete, production-ready inference engine.
Finding a passage does not establish that it supports a claim.
The prototype has not been validated for real client files or legal reliability.
See the [French README](README.md) for setup, documentation and limitations.
